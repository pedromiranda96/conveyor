# Design references

Paste reference screenshots into this folder before running `$conveyor-design`. PNG, JPEG, and WebP are suitable. One reference is usually enough.

When supplying multiple images, name them after what you want to borrow:

```text
composition.png
hero.png
typography.png
footer.png
```

Use suffixes when needed, such as `hero-01.png`. You can also explain the intended influence in your prompt. The agent will ask when the filename or your instructions do not make that clear; a filename cannot describe every design choice.

References guide presentation. The business brief determines the content and goals. Screenshots are not permission to reuse another business's logo, copy, or photography.

If there are no usable reference images, the agent will ask whether to proceed without them. If you agree, it will propose multiple directions for you to choose from.

Generated artifacts go in `.conveyor/generated/`; keep reference inputs here.
